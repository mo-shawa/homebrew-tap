# Homebrew tap

Install Cmd-Space Launcher on macOS with

```sh
brew install --cask mo-shawa/tap/cmd-space-launcher
```

The cask installs Hammerspoon, builds the native search panel, disables Spotlight’s Cmd-Space shortcut, and enables switching to the selected app’s Space. Grant Hammerspoon Accessibility access on first use. [Launcher source and setup instructions](https://github.com/mo-shawa/cmd-space-launcher#install)
